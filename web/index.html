app/todos/services.py
# Cross-module dependency, declared as a plain annotation.
class TodoService(TodoServiceABC):
    todo_repo: TodoRepoABC        # Infrastructure
    user_service: UserServiceABC   # another module

    async def create_todo(self, payload):
        # reuse the users domain to validate ownership
        await self.user_service.ensure_exists(payload.user_id)
        todo = await self.todo_repo.create(
            title=payload.title, user_id=payload.user_id,
            color=payload.color, group=payload.group,
        )
        return serialize(TodoDM, todo)

How a request flows

archtool builds the graph from class annotations and refuses to start if an inner layer reaches outward. A controller may call a service, a service a repository, never the reverse.

calls inward (allowed) cross-module dependency, same layer

The five endpoints

Two for users, three for tasks. The ToDo app uses every one of them. Domain errors map to HTTP codes only inside the controller.

MethodPathWhat it does
POST/users/Register a user from email and name
GET/users/{id}Fetch one user, or 404
POST/todos/Create a task (title, color, group) for a user
GET/todos/?user_id=List every task for a user
PATCH/todos/{id}/completeMark a task done
